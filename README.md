# Deep Learning Projects

A collection of **Deep Learning projects developed during the final months of my Bachelor of Technology (B.Tech.)**.

These projects represent my early hands-on work with **Artificial Neural Networks, Convolutional Neural Networks, Computer Vision, and Deep Learning model development** using Python and the TensorFlow/Keras ecosystem.

The repository is preserved as an archive of the projects I built while exploring practical applications of Deep Learning towards the end of my undergraduate studies.

---

## Projects

### ✍️ Handwritten Digit Recognition — CNN

A Convolutional Neural Network based project for recognizing handwritten digits.

The project explores the complete workflow of an image classification problem, including:

* Image/data preprocessing
* Building a CNN architecture
* Model training
* Model evaluation
* Prediction on handwritten digit samples
* Saving and reusing trained models

Two trained model artifacts are included in the repository:

* `HandwritingRecogCNN-Model-A.h5`
* `HandwritingRecogCNN-Model-B.h5`

**Focus:** Computer Vision, CNN, Image Classification

---

### 🎬 Movie Collection Prediction — Artificial Neural Network

A Deep Learning project using a **Multi-Layer Perceptron (MLP) / Artificial Neural Network (ANN)** for predicting movie collection-related outcomes.

The project includes separate input and target data files and demonstrates the process of preparing structured data for a neural-network-based prediction model.

Included data files:

* `Movie_collection_Independent.csv`
* `Movie_collection_Target.csv`

The trained model is preserved as:

* `MovieCollectionPred-Model.h5`

**Focus:** ANN, MLP, Regression/Prediction, Structured Data

---

### 😷 COVID-19 Face Mask Detection — CNN

A Computer Vision project developed during the COVID-19 period to explore **face mask detection using a Convolutional Neural Network**.

The project demonstrates the application of Deep Learning to image-based classification and explores how CNNs can be used to identify whether a face is associated with mask usage.

The original trained model and large project artifacts are hosted separately on Hugging Face to keep this GitHub repository lightweight.

**Model & Artifacts:**
[Hugging Face — COVID Face Mask Detection](https://huggingface.co/kaisermanishgupta/covid-facemask-detection)

**Focus:** Computer Vision, CNN, Image Classification, COVID-19 Face Mask Detection
